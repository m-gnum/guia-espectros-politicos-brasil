# Guia dos espectros políticos no Brasil

Guia didático sobre o espectro esquerda-direita, com foco no Brasil: de onde vêm os nomes, o que é o centrão, meritocracia, cinco posições (esquerda radical, social-democracia, centro, direita e extrema-direita), o que cada uma pensa sobre economia, segurança pública, Estado e funcionalismo, costumes e meio ambiente, e um simulador para o leitor montar o próprio perfil.

Página única em HTML, sem dependências além das fontes do Google Fonts. Abra o `index.html` ou acesse a versão publicada no GitHub Pages.

Os eixos usados como referência vêm do [12axes](https://12axes.vercel.app/br).
